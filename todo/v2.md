## 分组功能支持

---

### 1. 核心概念 (Core Concept)

*   **默认分组 (Default)**：系统保留一个默认分组（类似于现在的列表），新用户或未指定分组时默认使用此组。
*   **多重归属 (Many-to-Many)**：同一个文件可以同时存在于多个分组中（例如 `User.java` 既属于 "Auth" 分组，也属于 "Database" 分组）。
*   **当前激活 (Active Group)**：ToolWindow 界面上始终有一个“当前选中的分组”，所有的“复制 Markdown”操作都仅针对当前分组。

---

### 2. 数据存储设计 (.aicode.json)

目前的结构是一个简单的字符串数组：
```json
["src/main/java/App.java", "README.md"]
```

**新结构提案**：
改为对象结构，支持多个 Key，每个 Key 代表一个分组名。

```json
{
  "Default": [
    "src/main/java/App.java",
    "README.md"
  ],
  "LoginFeature": [
    "src/main/java/App.java",  // 文件可以在多个组
    "src/main/java/LoginService.java"
  ],
  "UI_Fix": [
    "src/main/resources/styles.css"
  ]
}
```

*   **兼容性**：代码需要处理旧版本（数组）到新版本（对象）的自动迁移。

### 3. UI/UX 交互设计

#### A. 工具窗口 (AICode Tool Window)
**布局变化**：
在工具栏最上方（Refresh 按钮旁边或上面）增加一个 **ComboBox (下拉选择框)** 和几个小按钮。

*   **[下拉框]**：显示当前所有分组（默认为 `Default`）。切换下拉框，下方的文件树随即刷新，只显示该分组内的文件。
*   **[+] 按钮**：点击弹出对话框 "Create New Context Group"，输入名字后创建一个空分组并切换过去。
*   **[-] 按钮**：删除当前选中的分组（需二次确认）。注：`Default` 分组不可删除。
*   **[重命名] 按钮**（可选）：重命名当前分组。

#### B. 右键菜单 (Project View / Tab Context Menu)
这是交互最关键的地方，体验要丝滑。

**场景 1：如果只有一个分组 (Default)**
*   保持现状：`Add to AICode` -> 直接加入 Default。

**场景 2：如果有多个分组**
*   `Add to AICode` 变成一个 **子菜单 (Submenu)**：
    *   `Default`
    *   `LoginFeature`
    *   `UI_Fix`
    *   ------
    *   `[+] New Group...` (快捷新建并添加)

**场景 3：Remove 操作**
*   `Remove from AICode`：从**当前激活的分组**（或者所有包含该文件的分组）中移除？
    *   *建议策略*：如果只在当前组，直接移除。如果该文件存在于多个组，弹窗询问或提供子菜单 `Remove from Default`, `Remove from LoginFeature`。
    *   *简化策略（推荐）*：右键菜单的 Remove 操作，仅从**当前 ToolWindow 选中的分组**中移除该文件（如果在该组内的话）。如果要管理复杂关系，建议去 ToolWindow 操作。

#### C. 文件树内部交互 (Tree View)
*   **支持拖拽 (Drag & Drop)**：(进阶需求，暂不做) 将文件从 Project 视图拖入特定的分组。
*   **右键移除**：在 AICode 面板的文件树上右键 -> `Remove`，仅从当前显示的分组中移除。

### 4. 业务逻辑细节

1.  **复制为 Markdown (Copy)**：
    *   逻辑变更：不再读取所有文件，而是读取 **当前下拉框选中的分组** 下的文件列表进行打包。
2.  **文件监听 (File Listener)**：
    *   重命名/移动文件：必须遍历 JSON 中所有的分组，更新所有出现该路径的地方。
    *   删除文件：遍历所有分组，移除该路径。
3.  **去重**：
    *   同一个分组内不能有重复文件（Set 结构）。

### 5. 预期用户故事 (User Story)

1.  **场景：开发新功能**
    *   我正在开发“微信支付”功能。
    *   我在 AICode 面板新建分组 "WeChatPay"。
    *   我在 Project 视图中选中 `PaymentService.java` 和 `WeChatConfig.java`，右键 -> `Add to AICode` -> `WeChatPay`。
    *   我点击 Copy，发给 ChatGPT，此时上下文非常纯净，只有支付相关的代码。

2.  **场景：切换任务**
    *   突然有个线上 Bug 需要修。
    *   我在 AICode 面板下拉框切换回 "Default" (或者新建 "BugFix_101")。
    *   之前的 "WeChatPay" 上下文被保留，互不干扰。

3.  **阶段三：右键菜单升级**
    *   改造 `AddAction`，支持动态生成子菜单。
